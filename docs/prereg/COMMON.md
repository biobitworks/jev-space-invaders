# S01 preregistration — common terms (E0–E4A)

**Timing disclosure.** These documents were written before any E0–E4A execution. The first executions were rehearsals in the Claude sandbox (Linux x86_64, Python 3.12). Sealing happens later, when the prereg breakpoint is created on the playing machine. The sealed breakpoint therefore proves *identity* of these texts, **not** that they predate the rehearsal. Rehearsal output digests are kept in `evidence/s01/REFERENCE_RUNTIME_DIGESTS.json` for cross-runtime comparison only.

**System 0 in this ladder is the public reference provider** (exact consistency filtering, exact world counting, public operator-declared Anticube labels). Private System-0 kernels are absent from this repository. Every private arm is `NOT_TESTED`: Anticube math, ΔG*, Golden-Corridor ranking, private commitments.

**Terminal states:** SUPPORTED, NOT_SUPPORTED, FAIL_TO_REJECT_H0, NULL, NEGATIVE, PARTIAL, FAILED, DEFERRED, CREDIT_EXHAUSTED, ABSTAIN, NOT_TESTED.

An experiment is complete only when it has all of: run, output dataset, validation, breakpoint, and remote verification.
